## What is this tool?
Open-code-review helps you improve your computer code. It finds errors that cause programs to crash or behave in unexpected ways. It acts as an assistant that looks at your work line by line. It identifies problems like security risks, memory leaks, and logic errors before you finish your project. The tool uses both simple logic and advanced artificial intelligence to offer feedback on your files.

## 💻 System requirements
You need a computer running Windows 10 or Windows 11. Your computer should have at least 8 GB of RAM and 500 MB of free storage space. Ensure you maintain an active internet connection to receive updates and connect to external analysis services. You do not need to install complex programming runtimes if you download the standalone executable file.

## 🚀 Getting started
Once installed, open the application from your desktop shortcut or the Windows Start menu. You will see a clean main screen with a box for your file path. 

**Loading your first project:**
1. Click the "Browse" button.
2. Select the folder containing the code you want to check.
3. Click "Load" to allow the tool to index your files.

**Running a review:**
1. Select the type of check you want to perform. The tool uses predefined sets of rules to scan for common mistakes. These rules check for issues like thread-safety, XSS vulnerabilities, and SQL injection flaws.
2. Click the "Start Review" button.
3. Wait for the progress bar to finish.
4. The tool will display a list of findings on the right side of the screen.

**Reviewing feedback:**
The tool highlights specific lines in your code. Click on any highlighted error to read a simple explanation of why the tool flagged that section. You can choose to ignore the finding or mark it as fixed.

## ⚙️ Configuring features
You can connect your own external services to the tool for more detailed analysis.

1. Go to the "Settings" tab in the top menu.
2. Select "API Keys."
3. Enter your keys for external services like OpenAI or Anthropic if you want more advanced advice on your code.
4. Click "Save" to apply your changes.

The tool uses these services to understand the context of your entire project. This helps the agent provide better suggestions that fit your specific coding style.

## 🛠 Solving common issues
If the program does not start, check for these common fixes:

* **Antivirus settings:** Sometimes security software blocks new programs. Check your antivirus history to see if it quarantined the application. If so, add the program to your "Exclusion" list.
* **Updates:** Check the download link provided above regularly. We release improvements often. If you encounter bugs, downloading the latest version usually solves the problem.
* **Network issues:** If the scan stalls, verify your internet connection. The application requires a connection to reach the external AI agents for deep code analysis.
* **Memory usage:** If the tool closes suddenly while scanning huge projects, try closing other heavy apps like web browsers or video editors. Large projects consume a significant amount of system memory.
